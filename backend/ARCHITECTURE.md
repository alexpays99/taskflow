## Компоненти системи

### 1. DNS — телефонна книга інтернету

```
api.taskflow.app — це просто ІМ'Я
142.93.167.45    — це реальна АДРЕСА (IP сервера)

DNS = телефонна книга яка каже:
"api.taskflow.app" → "142.93.167.45"

АНАЛОГІЯ:
"Піца Челентано" — це назва
"вул. Хрещатик 15" — це реальна адреса

Google Maps = DNS
Ти кажеш "Челентано" → він каже куди їхати
```

### 2. Cloudflare / Route53 — де записується "телефонна книга"

```
Cloudflare = сайт де ти кажеш:
"Мій домен api.taskflow.app має вести на IP 142.93.167.45"

Route53 = те саме, але від Amazon (AWS)

АНАЛОГІЯ:
Cloudflare = Жовті сторінки
Ти платиш щоб твій бізнес там був записаний
Люди шукають "Піца Челентано" → знаходять адресу
```

### 3. Сервер (VPS) — комп'ютер який працює 24/7

```
Сервер = звичайний комп'ютер, але:
• Стоїть в дата-центрі (велика зала з комп'ютерами)
• Працює 24/7 без вимкнення
• Підключений до швидкого інтернету
• Має публічний IP (142.93.167.45)

АНАЛОГІЯ:
Твій MacBook = твоя квартира (працює коли ти вдома)
Сервер = офіс (працює завжди, є адреса для клієнтів)

Де взяти сервер?
• DigitalOcean — $6/міс (простий, для початківців)
• Hetzner — $4/міс (дешевший)
• AWS EC2 — складніший, для великих компаній
```

### 4. Nginx — охоронець на вході

```
Запит прилітає на сервер. Але на сервері може бути
багато додатків! Хто вирішує куди направити?

Nginx = охоронець/адміністратор на ресепшені

Запит на api.taskflow.app   → направь в NestJS (порт 3000)
Запит на taskflow.app       → направь в Frontend
Запит на admin.taskflow.app → направь в Admin панель

АНАЛОГІЯ:
Бізнес-центр з багатьма офісами
Nginx = охоронець на вході
"Вам до TaskFlow? 3-й поверх, офіс 301"
"Вам до іншої компанії? 5-й поверх, офіс 512"

Traefik = те саме що Nginx, просто інша програма
```

### 5. Docker — коробка з твоїм кодом

```
Проблема: На твоєму MacBook NestJS працює.
         На сервері може НЕ працювати (інша версія Node,
         інші бібліотеки, інша ОС...)

Docker = пакуєш КОД + ВСІ ЗАЛЕЖНОСТІ в одну коробку
         Ця коробка працює ОДНАКОВО скрізь

АНАЛОГІЯ:
Переїзд в новий офіс

Без Docker: перевозиш меблі → в новому офісі двері
           вужчі, шафа не влазить, треба переробляти

З Docker: перевозиш ЦІЛУ КІМНАТУ разом зі стінами
         Ставиш її в новий офіс → все працює
```

### 6. PostgreSQL — шафа з документами

```
База даних = місце де зберігаються ВСІ дані
• Користувачі (email, пароль, ім'я)
• Задачі (title, description, isCompleted)

АНАЛОГІЯ:
PostgreSQL = величезна шафа з папками
Кожна таблиця = одна папка
Кожен рядок = один документ в папці

NestJS каже: "Дай мені документ користувача #123"
PostgreSQL шукає і віддає
```

### 7. AWS S3 — склад для файлів

```
Проблема: Користувач завантажує аватарку.
         Куди її зберегти?

Варіант 1: В папку на сервері (./uploads/)
           ❌ Сервер перезапустився — файли зникли

Варіант 2: AWS S3
           ✅ Окреме сховище, файли ніколи не зникнуть

АНАЛОГІЯ:
./uploads/ = тримаєш документи на робочому столі
            (прибрали стіл — документи зникли)

AWS S3 = орендуєш комірку в банку
        (що б не сталось — документи в безпеці)
```

### 8. Kubernetes — менеджер для багатьох серверів

```
Kubernetes = менеджер для БАГАТЬОХ Docker контейнерів

Потрібен коли:
• 10+ серверів
• Треба автоматично масштабувати
• Netflix, Google, великі компанії

НЕ потрібен коли:
• 1-3 сервери
• Стартап / pet project
• TaskFlow зараз
```

## Повний шлях запиту

```
Мобільний додаток
"Хочу залогінитись на api.taskflow.app"
       │
       ▼
DNS (Cloudflare)
"api.taskflow.app це IP 142.93.167.45"
       │
       ▼
Сервер (DigitalOcean)
Комп'ютер з цим IP
       │
       ▼
Nginx (охоронець)
"Запит на API? Направляю в Docker контейнер"
       │
       ▼
Docker (коробка)
Всередині крутиться NestJS
       │
       ▼
NestJS (твій код)
"Логін? Зараз перевірю пароль в базі"
       │
       ▼
PostgreSQL (база)
"Ось дані користувача з email = ..."
       │
       ▼
NestJS
"Пароль вірний! Ось токен"
       │
       ▼
Мобільний додаток
"Отримав токен, зберігаю, переходжу на головний екран"
```

## Environments (середовища)

```
development  → https://dev-api.taskflow.app     (для розробки)
staging      → https://staging-api.taskflow.app (для тестування)
production   → https://api.taskflow.app         (для користувачів)
```

### Команди запуску

```bash
npm run start:dev      # → .env.development
npm run start:staging  # → .env.staging
npm run start:prod     # → .env.production
```

## Що налаштовано в TaskFlow

| Компонент | Статус | Коментар |
|-----------|--------|----------|
| NestJS | ✅ Є | Код в `/backend/src` |
| PostgreSQL | ✅ Є | `docker-compose up db` |
| Docker для NestJS | ✅ Є | Dockerfile є |
| Environments | ✅ Є | .env.development, .env.staging, .env.production |
| Сервер | ❌ Нема | Поки localhost |
| DNS (Cloudflare) | ❌ Нема | Треба коли купиш домен |
| Nginx | ❌ Нема | Треба на сервері |
| AWS S3 | ❌ Нема | Поки `./uploads/` |

## Локальна розробка

```bash
# 1. Запустити PostgreSQL
docker-compose up db -d

# 2. Запустити NestJS
npm run start:dev

# Готово! API доступний на http://localhost:3000
# Swagger документація: http://localhost:3000/api/docs
```

## Що потрібно для продакшену

1. **Сервер** — DigitalOcean Droplet ($6/міс)
2. **Домен** — taskflow.app (~$12/рік)
3. **DNS** — Cloudflare (безкоштовно)
4. **SSL сертифікат** — Let's Encrypt через Cloudflare (безкоштовно)
5. **База даних** — DigitalOcean Managed PostgreSQL ($15/міс) або на тому ж сервері
6. **Файлове сховище** — DigitalOcean Spaces або AWS S3 ($5/міс)

**Мінімальний бюджет для старту: ~$25/міс**
